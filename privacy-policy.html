プライバシーポリシー

本ポリシーは、開発者本人が個人環境（Cursor）で利用する 「Google Calendar MCP」向け OAuth アプリケーション（Google Cloud プロジェクト: caramel-howl）に適用されます。

1. 取得する情報

Google OAuth を通じて、本人の Google アカウントに紐づく Google カレンダーの予定情報（タイトル、日時、説明など）を読み取り、表示・操作のために利用します。

2. 利用目的

  • 本人のカレンダー予定の参照・作成・更新・削除（MCP 経由の個人利用）
  • 上記以外の目的には使用しません

3. 第三者への提供

取得したデータを第三者に販売・共有・提供しません。 広告配信やプロファイリングにも使用しません。

4. データの保存場所

OAuth のアクセストークンおよびリフレッシュトークンは、 利用者本人のコンピュータ上（例: ~/.cursor/ 配下のローカルファイル）にのみ保存されます。 開発者によるリモートサーバーへのトークン保存は行いません。

5. Google API サービスのユーザー データ ポリシー

本アプリの Google API からの情報の使用および他アプリへの転送は、 Google API Services User Data Policy （Limited Use 要件を含む）に従います。
